# images

Visuals for my favorite things.

## Naming
Lowercase with hyphens, starting with the topic, so they sort together:
`travel-skydiving-1.jpg`, `food-sushi-omakase.jpg`, `fashion-bag-black-tote.jpg`, `film-tv-one-piece-luffy.png`

Topic prefixes: `fashion`, `food`, `travel`, `film-tv`, `concerts`, `friends`.

## Linking a picture to an entry
In the entry's front matter, add the path:

```yaml
images: [images/food-sushi-omakase.jpg]
```

Keep files reasonably small (under about 5 MB each). Resize big phone photos before adding them.
